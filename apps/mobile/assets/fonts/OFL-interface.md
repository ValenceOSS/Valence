# Interface fonts

The fonts in this folder named below set the phone app's interface. Each is licensed under the SIL
Open Font License 1.1 (https://openfontlicense.org):

| File                    | Font              | Copyright                                                                                          |
| ----------------------- | ----------------- | -------------------------------------------------------------------------------------------------- |
| `PlusJakartaSans-*.ttf` | Plus Jakarta Sans | Copyright 2020 The Plus Jakarta Sans Project Authors (https://github.com/tokotype/PlusJakartaSans) |
| `Manrope-*.ttf`         | Manrope           | Copyright 2019 The Manrope Project Authors (https://github.com/sharanda/manrope)                   |

Plus Jakarta Sans is version 2.7.1 from its project's release. Its ascent and descent are set to
84% and 16% of the em with no line gap, the same as the web sets them, so text sits in its line as
it did before. Nothing else about it is changed.
