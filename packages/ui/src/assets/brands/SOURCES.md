# Brand marks

The marks of the browsers, systems and televisions a session can be watched on, so the admin can say at a
glance what a session is running in, and of the places the project lives, for the sites'
footer. Each is one file from
[Simple Icons](https://simpleicons.org) 16.33.0, which releases them under
[CC0 1.0](https://github.com/simple-icons/simple-icons/blob/develop/LICENSE.md). They are kept as
files and drawn through a CSS mask by `BrandGlyph`, so no SVG is ever inlined.

| File                 | Mark          |
| -------------------- | ------------- |
| `android.svg`        | Android       |
| `apple.svg`          | Apple         |
| `brave.svg`          | Brave         |
| `discord.svg`        | Discord       |
| `docker.svg`         | Docker        |
| `firefoxbrowser.svg` | Firefox       |
| `github.svg`         | GitHub        |
| `googlechrome.svg`   | Google Chrome |
| `lg.svg`             | LG            |
| `linux.svg`          | Linux         |
| `opera.svg`          | Opera         |
| `safari.svg`         | Safari        |
| `samsung.svg`        | Samsung       |
| `vivaldi.svg`        | Vivaldi       |

Simple Icons no longer carries Microsoft's marks, at Microsoft's request, and has none for ChromeOS,
so Edge, Windows, ChromeOS and an Xbox keep a generic shape. A browser that says only that it is built on
Chromium is shown with Chrome's mark: its user agent cannot be told apart from Chrome's, and Chrome
is the one it almost always is.
