# Doodles

The hand-drawn marks the landing site uses to point at things: a ring drawn round a word, an arrow
curling towards a note, a line underneath, a few sparks. They were drawn for Valence, so they are
its own and carry no outside licence. Each is a stroked path kept as a file and drawn through a CSS
mask by `Doodle`, which also sweeps a second mask along it so it draws itself in; no SVG is inlined.

| File             | Mark                                                |
| ---------------- | --------------------------------------------------- |
| `arrow-curl.svg` | An arrow that loops once, pointing right            |
| `arrow-down.svg` | An arrow that bends, pointing down                  |
| `circle.svg`     | A ring drawn round a word                           |
| `sparks.svg`     | Three short strokes of emphasis                     |
| `underline.svg`  | A wavering line beneath a word                      |
